# Forecast Aeropuertos (AICM & AIFA)

Modelo de predicción diaria usando XGBoost.

## Resultados

- AICM: MAPE ~1.15%
- AIFA: MAPE ~3.10%

## Metodología

- Feature engineering (lags, rolling stats)
- Backtesting walk-forward
- Interpretabilidad con SHAP

## Uso

Ejecutar script o notebook en Google Colab.
